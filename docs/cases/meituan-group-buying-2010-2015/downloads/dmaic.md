# DMAIC（事后映射）：美团百团大战：从团购价格战到本地供给密度与组织效率

> 研究时段：2010—2015｜公司：美团 Meituan｜行业：本地生活服务 / 团购平台 / O2O

> 方法学声明：本案例是事后研究复盘；James 七连问仅为研究重建，DMAIC 是方法论映射，除非另有确证，不代表案例企业使用过这些制度。

## 执行摘要

2010年美团进入门槛较低的网络团购赛道；2011年5月行业已出现约4500家团购网站。美团管理层事后描述的关键决策包括早期扩张二三线城市、2011年重视获客效率、2012年从“一日一团”转为“一日多团”，以及建设地推、CRM和人才培养体系。王兴在2015年采访中称2013年底份额约50%、2014年约60%，2015年10月美团与大众点评宣布合并。本报告以可追溯材料重建竞争机制，但不把公司自报份额、管理者事后解释和严格因果证明混为一谈。

**核心判断：** 以城市/品类为改进单元，围绕有效商户供给、团单质量、销售生产率、交易履约和现金纪律建立持续优化体系，而非把多开城市本身当目标。

## 第一部分：理解现实与明确边界

**战略命题：** 决定团购平台长期位置的不只是补贴和广告预算，而是城市级供给覆盖、商户合作持续性、消费者本地选择、单位获客效率和线下组织的共同作用。行业资本收缩与竞争者失误也可能显著影响结果。

### 核验过的关键经营指标

|指标|观察值|口径与限制|来源|
|---|---:|---|---|
|2011年5月团购网站数|约4,500家|团800截至2011年5月底的估计；不是市场活跃商家数|[S1](#s1)|
|美团2011年5月销售额|7,520.2万元|团800统计的单月团购销售额，非平台净营收|[S1](#s1)|
|2013年底团购份额|约50%|王兴于2015年回顾的交易额市场份额；公司自报|[S3](#s3)|
|2014年团购份额|约60%|王兴2015年所述；不同于CNNIC 56.6%的品牌渗透率|[S3](#s3)|
|2014年平台交易额|超过460亿元|2015年访谈报道引用的2014全年交易额；不是收入或利润|[S3](#s3)|

### 经历的主要节点

- **2010年3月｜美团网成立：** 进入Groupon式团购市场，后逐渐以本地生活服务为主。 [S4]
- **2010年下半年｜竞争从一线城市转向多城市布局：** 杨俊在2014年演讲中回顾，团队最终选择优先拓展二三四线市场而非只深耕北上广深。 [S2]
- **2011年5月｜赛道拥挤、早期排名变化：** 团800统计行业网站约4500家，美团该月销售额7520.2万元，在所统计网站中排名第一。 [S1]
- **2011—2012年｜资本退潮与获客效率竞争：** 杨俊回顾称美团偏向购买可测量的线上流量，而部分竞争者重投品牌广告；具体投放ROI未完整披露。 [S2]
- **2012年初｜一日多团：产品逻辑改变：** 从有限爆款转向丰富的城市级SKU与周边商户匹配，推动规模化地推组织。 [S2]
- **2013年｜向本地生活多品类延伸：** 官方报告记载1月上线酒店服务，11月推出外卖服务。 [S4]
- **2013年底—2014年｜行业集中与交易增长：** 王兴事后称2013年底团购份额约50%，2014年约60%，2014年交易额超460亿元。 [S3]
- **2015年10月8日｜美团与大众点评宣布战略合并：** 两家公司共同成立新公司，初期保留各自品牌并设置联席CEO。 [S5]

## 第二部分：DMAIC（事后映射）分析

**方法目的：** 把城市级供给扩张转换为可持续的地推、交易与质量系统

### 1. Define 定义

**核心追问：** 为什么增加城市和商户数量，仍可能无法满足消费者“此时此地”的需求？

**证据支持的观察：** 2012年前后美团从“一日一团”转向“一日多团”，针对用户需要周边、即时且多样选择的场景。

**反证与不确定性：** 对问题的DMAIC表述为本研究重建，没有发现当年正式六西格玛项目章程。

**建议的下一行动：** 定义CTQ：可发现有效SKU、真实可核销商户、订单履约及用户复购；按城市/品类界定范围。

证据索引：[S2](#s2)

### 2. Measure 测量

**核心追问：** 应如何衡量地推效率，而不仅是签了多少家店？

**证据支持的观察：** 杨俊介绍内部移动CRM支持拜访、找商户、汇报和人员管理；王兴强调城市内商户与消费者双侧密度。

**反证与不确定性：** 公开材料没有客户生命周期、获客成本、核销率、商户留存的统一原始数据。

**建议的下一行动：** 建议建设城市/品类仪表盘：有效SKU、核销成功率、商家续约、CAC、现金消耗和投诉。

证据索引：[S2](#s2), [S3](#s3)

### 3. Analyze 分析

**核心追问：** 供给不足源于拜访频次低、商家质量差、选品错位还是线上展示不匹配？

**证据支持的观察：** 2012年“一日多团”与线下持续“上单”同时推进，表明产品供给和线下组织之间存在协同需求。

**反证与不确定性：** 组织与产品同步变化，无法从结果中隔离单项措施贡献。

**建议的下一行动：** 按城市成熟度、商家类别、BD队伍、移动用户密度分层分析瓶颈，审计商家净收益。

证据索引：[S2](#s2)

### 4. Improve 改进

**核心追问：** 采取哪些能低成本增加真正可用选择的行动？

**证据支持的观察：** 管理层披露持续上架更多团单、部署销售移动CRM、建设培训与储备干部制度，并对垂直品类逐渐组织化。

**反证与不确定性：** 实际动作可确认，但没有A/B随机实验、改进前后统计置信区间。

**建议的下一行动：** 优先小范围优化商户准入、SKU可得性、销售拜访路线、退款体验和合理佣金。

证据索引：[S2](#s2)

### 5. Control 控制

**核心追问：** 增长之后怎样防止服务质量、现金流和团队执行失控？

**证据支持的观察：** 杨俊提到CRM、人员培养和制度；2011团800报告已显示整个行业投诉风险，美团强调低毛利与效率。

**反证与不确定性：** 缺乏已核实的正式SPC控制图或故障率控制界限；不得虚构。

**建议的下一行动：** 设商户流失/退款/投诉/现金消耗告警，按城市复盘，必要时暂停不合格团单扩张。

证据索引：[S1](#s1), [S2](#s2), [S3](#s3)

## 第三部分：管理含义与决策边界

**战略建议（研究解释，不代表历史管理会议原话）：**

以城市/品类为改进单元，围绕有效商户供给、团单质量、销售生产率、交易履约和现金纪律建立持续优化体系，而非把多开城市本身当目标。

### 证据与归因边界

- **公司自述与第三方数据须区分：** 公开采访中的口径、独立行业统计、正式披露的指标可能不同，不能直接拼接。
- **交易额、收入、利润与市场份额并不相等：** 使用前必须明确期间、分子分母与统计范围。
- **战略同时发生与严格因果归因并不相等：** 投资环境、竞争者反应和行业变化均可能影响结果。
- **成功叙事仍须允许反例：** 要审查行业淘汰者、竞争者领先区域与商户/消费者的不同体验。
- **DMAIC是方法映射：** 不得声称存在未经证实的控制图、控制限或试验结果。
- **战术有效不等于合法可持续：** 现金安全、消费者权益、商户价值和合规属于独立硬约束。

### 下一轮研究行动

- **Measure 测量：** 建议建设城市/品类仪表盘：有效SKU、核销成功率、商家续约、CAC、现金消耗和投诉。
- **Analyze 分析：** 按城市成熟度、商家类别、BD队伍、移动用户密度分层分析瓶颈，审计商家净收益。
- **Improve 改进：** 优先小范围优化商户准入、SKU可得性、销售拜访路线、退款体验和合理佣金。
- **Control 控制：** 设商户流失/退款/投诉/现金消耗告警，按城市复盘，必要时暂停不合格团单扩张。
