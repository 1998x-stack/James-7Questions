# James 七连问：实验驱动的业务决策：Booking.com：把实验文化变成竞争能力

> 研究时段：2017—2019｜公司：Booking.com / 缤客｜行业：在线旅游 / 住宿预订平台 / 实验组织

> 方法学声明：本案例是事后研究复盘；James 七连问仅为研究重建，DMAIC 是方法论映射，除非另有确证，不代表案例企业使用过这些制度。

## 执行摘要

2018年10月，哈佛商学院以Booking.com的线上实验和创新管理为主题推出案例619015。公开材料显示，Booking.com技术团队用随机对照与CUPED辅助产品决策；2017年一个挑战既有首页的方案后来成为管理学讨论的实例。同一时期，Booking Holdings集团2018年预订间夜达7.60亿，同比增长12.9%，同时对绩效营销渠道投入44.47亿美元。研究通过五力、苏格拉底式追问、James七问及事后DMAIC，考察实验学习机制的价值及边界，避免将集团增长全部归因于实验数量。

**核心判断：** 将市场边界、规模、竞争、因果、杠杆、反证和90天验证连成一条可审计决策链。

## 第一部分：理解现实与明确边界

**战略命题：** 可规模化的随机实验是一种组织学习能力而非孤立技术：它可以通过缩短假设—测量—改进周期提升产品决策质量，但只有与供给、客户关系、营销效率和长期净价值管理协同才能成为可持续竞争力。

### 经历的主要节点

- **2017年｜产品实验基础进入成熟讨论：** Booking.com团队已广泛使用A/B试验；一项挑战原有首页设计的方案被提出。 [S3]
- **2018年1月22日｜发布实验统计工程实践：** Booking.com技术团队公开CUPED与A/B测试方差缩减的使用逻辑。 [S4]
- **2018年10月15日｜HBS出版Booking.com案例：** Stefan Thomke与Daniela Beyersdorfer的案例619015讨论实验如何影响数字体验与创新管理。 [S1]
- **2018年全年｜规模扩张与营销并存：** Booking Holdings集团760百万预订间夜、绩效营销约44.47亿美元；增长因素包括供给、营销及在线化。 [S2]
- **2019年3月31日｜供给规模披露：** 集团公告Booking.com上有约229万家可直接预订酒店及其他住宿设施，单位并非客房数。 [S11]
- **2019年｜HBS Working Knowledge总结实验组织：** 讨论随机对照、对结果的遵从及员工广泛参与。 [S7]
- **2020年3月｜HBR阐述实验文化：** Thomke发表Building a Culture of Experimentation，提及每年约2.5万测试及组织文化原则。 [S3]

## 第二部分：James 七连问：实验驱动的业务决策分析

**方法目的：** 研究重建七阶段，不代表梁建章或Booking.com有官方固定七问

### 1. 市场边界

**核心追问：** Booking.com实际竞争的是“酒店列表展示”还是“住宿需求到可履约订单”？

**证据支持的观察：** 核心市场可定义为住宿预订撮合平台；跨地域竞争含OTA、住宿直销、元搜索及替代住宿，须兼顾旅客与酒店两端。

**反证与不确定性：** 本定义是研究框架，不等于任何监管机关在特定案件中的相关市场划分。

**建议的下一行动：** 按国家、订单与入住状态、客群和住宿类型定义可比较的子市场。

证据索引：[S1](#s1), [S6](#s6)

### 2. 规模及增长

**核心追问：** 2018年的增长有多大，规模来源是什么？

**证据支持的观察：** Booking Holdings集团2017年预订间夜673百万，2018年760百万，同比增长12.9%；费用和供给规模也同步增长。

**反证与不确定性：** 集团预订间夜非Booking.com单品牌订单；与Expedia已入住间夜或收入口径不可直接合并。

**建议的下一行动：** 测算各市场净间夜、订单价值与利润池，区分自然需求增长、营销投入和转化改善。

证据索引：[S2](#s2), [S11](#s11)

### 3. 竞争格局

**核心追问：** 竞品、酒店集团和搜索入口都掌握什么权力？

**证据支持的观察：** Expedia同业竞争强劲，搜索与元搜索影响流量分发，酒店与替代住宿提供供给，用户有多平台比价选项。

**反证与不确定性：** 不能以两个集团的跨定义指标计算所谓全球OTA市场份额。

**建议的下一行动：** 设计竞争地图：用户入口、渠道成本、可订供给与交易履约五维。

证据索引：[S6](#s6), [S2](#s2)

### 4. 因果机制

**核心追问：** 为何一个高频实验体系可能成为增长机制？

**证据支持的观察：** Booking.com技术团队使用随机对照与CUPED减少估计噪声，赋予产品团队验证假设的能力；这可缩短从意见到证据的学习路径。

**反证与不确定性：** 能降低局部决策失误，不等于可以量化解释集团增长；试验之间可能相互干扰。

**建议的下一行动：** 把“发布次数”变成“经复验的净长期价值提升/决策周期”的有效学习速度。

证据索引：[S4](#s4), [S7](#s7), [S3](#s3)

### 5. 战略杠杆

**核心追问：** 如果只能投一笔资金，先买流量、扩供给，还是提升实验基础设施？

**证据支持的观察：** 2018年集团绩效营销费用44.47亿美元且依赖搜索渠道；实验有机会提高每次流量的净价值，但同时需要有效供给支持。

**反证与不确定性：** 最优投资方向受具体市场瓶颈限制，公开材料不足以给出真实ROI排序。

**建议的下一行动：** 为流量、供给、实验工程三个选项建立可比较的增量净利润/投资额和风险区间。

证据索引：[S2](#s2), [S4](#s4), [S11](#s11)

### 6. 反证与约束

**核心追问：** 怎样证明“实验文化”不只是漂亮的管理故事？

**证据支持的观察：** 必须审查试验功效、选择性报告、重复检验、跨试验干扰和对消费者/酒店的长期外部影响；作者本人提出伦理与管理文化条件。

**反证与不确定性：** HBS教材的教学价值与公司实际经营成效不是同一个问题，不能复制未购买的案例正文。

**建议的下一行动：** 设置预注册、A/A健康检查、复现审核和商户/用户合规红线；查找失败试验样本。

证据索引：[S3](#s3), [S8](#s8), [S4](#s4)

### 7. 行动与验证

**核心追问：** 经营者下一季度如何验证实验文化对利润与客户价值是否有贡献？

**证据支持的观察：** 将高质量实验作为决策制度而非KPI数量竞赛，先从需求明确、样本充分、可复现的产品体验问题试点。

**反证与不确定性：** 下述90天试点为研究建议，非Booking.com在2018年曾使用的正式计划。

**建议的下一行动：** 30天建指标字典与A/A检测；30天在统一客群分流开展5—10个有功效设计的实验；30天复验长期净价值与用户/商户guardrails。

证据索引：[S4](#s4), [S7](#s7), [S2](#s2)

## 第三部分：管理含义与决策边界

**战略建议（研究解释，不代表历史管理会议原话）：**

将市场边界、规模、竞争、因果、杠杆、反证和90天验证连成一条可审计决策链。

### 证据与归因边界

- **公司自述与第三方数据须区分：** 公开采访中的口径、独立行业统计、正式披露的指标可能不同，不能直接拼接。
- **交易额、收入、利润与市场份额并不相等：** 使用前必须明确期间、分子分母与统计范围。
- **战略同时发生与严格因果归因并不相等：** 投资环境、竞争者反应和行业变化均可能影响结果。
- **成功叙事仍须允许反例：** 要审查行业淘汰者、竞争者领先区域与商户/消费者的不同体验。
- **DMAIC是方法映射：** 不得声称存在未经证实的控制图、控制限或试验结果。
- **战术有效不等于合法可持续：** 现金安全、消费者权益、商户价值和合规属于独立硬约束。

### 下一轮研究行动

- **因果机制：** 把“发布次数”变成“经复验的净长期价值提升/决策周期”的有效学习速度。
- **战略杠杆：** 为流量、供给、实验工程三个选项建立可比较的增量净利润/投资额和风险区间。
- **反证与约束：** 设置预注册、A/A健康检查、复现审核和商户/用户合规红线；查找失败试验样本。
- **行动与验证：** 30天建指标字典与A/A检测；30天在统一客群分流开展5—10个有功效设计的实验；30天复验长期净价值与用户/商户guardrails。
