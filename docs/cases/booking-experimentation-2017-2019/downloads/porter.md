# 波特五力：住宿平台的结构性竞争：Booking.com：把实验文化变成竞争能力

> 研究时段：2017—2019｜公司：Booking.com / 缤客｜行业：在线旅游 / 住宿预订平台 / 实验组织

> 方法学声明：本案例是事后研究复盘；James 七连问仅为研究重建，DMAIC 是方法论映射，除非另有确证，不代表案例企业使用过这些制度。

## 执行摘要

2018年10月，哈佛商学院以Booking.com的线上实验和创新管理为主题推出案例619015。公开材料显示，Booking.com技术团队用随机对照与CUPED辅助产品决策；2017年一个挑战既有首页的方案后来成为管理学讨论的实例。同一时期，Booking Holdings集团2018年预订间夜达7.60亿，同比增长12.9%，同时对绩效营销渠道投入44.47亿美元。研究通过五力、苏格拉底式追问、James七问及事后DMAIC，考察实验学习机制的价值及边界，避免将集团增长全部归因于实验数量。

**核心判断：** 用供给可用性、流量依赖、用户转换成本与净长期价值审查实验价值，不用不兼容的间夜指标拼凑市占率。

## 第一部分：理解现实与明确边界

**战略命题：** 可规模化的随机实验是一种组织学习能力而非孤立技术：它可以通过缩短假设—测量—改进周期提升产品决策质量，但只有与供给、客户关系、营销效率和长期净价值管理协同才能成为可持续竞争力。

### 经历的主要节点

- **2017年｜产品实验基础进入成熟讨论：** Booking.com团队已广泛使用A/B试验；一项挑战原有首页设计的方案被提出。 [S3]
- **2018年1月22日｜发布实验统计工程实践：** Booking.com技术团队公开CUPED与A/B测试方差缩减的使用逻辑。 [S4]
- **2018年10月15日｜HBS出版Booking.com案例：** Stefan Thomke与Daniela Beyersdorfer的案例619015讨论实验如何影响数字体验与创新管理。 [S1]
- **2018年全年｜规模扩张与营销并存：** Booking Holdings集团760百万预订间夜、绩效营销约44.47亿美元；增长因素包括供给、营销及在线化。 [S2]
- **2019年3月31日｜供给规模披露：** 集团公告Booking.com上有约229万家可直接预订酒店及其他住宿设施，单位并非客房数。 [S11]
- **2019年｜HBS Working Knowledge总结实验组织：** 讨论随机对照、对结果的遵从及员工广泛参与。 [S7]
- **2020年3月｜HBR阐述实验文化：** Thomke发表Building a Culture of Experimentation，提及每年约2.5万测试及组织文化原则。 [S3]

## 第二部分：波特五力：住宿平台的结构性竞争分析

**方法目的：** 实验能力能否突破流量与供给双边约束？

### 1. 现有竞争强度

**核心追问：** 与Expedia、区域OTA争夺同一批用户和住宿供给时，价格之外还能如何竞争？

**证据支持的观察：** Booking.com与Expedia等OTA在搜索效率、酒店供给、流量采购和交易服务上竞争。Expedia 2018年申报同时列明Google旅游搜索和区域OTA压力；实验体系是改进转化与体验的一种机制。

**反证与不确定性：** Expedia已入住间夜和Booking集团已预订间夜不同，不能以351.6/760推算市场份额或竞争胜负。

**建议的下一行动：** 按相同地域、渠道、客群和订单状态对齐后，再比较转化、重复预订、取消与有效客户终身价值。

证据索引：[S6](#s6), [S1](#s1), [S4](#s4)

### 2. 新进入者威胁

**核心追问：** 技术上可以建一个预订网站，为什么难以迅速复制Booking.com的表现？

**证据支持的观察：** 入场者需要获取住宿供给、消费者信任、营销流量与交易可靠性；不断实验改善运营决策，但不自动保证稳固壁垒。

**反证与不确定性：** 技术实验平台只是潜在能力，不是法律排他壁垒；新流量入口可能降低现有OTA优势。

**建议的下一行动：** 拆解进入成本为供给接入、认证及内容、获客、客服履约和实验治理五项。

证据索引：[S1](#s1), [S2](#s2), [S6](#s6)

### 3. 替代品威胁

**核心追问：** 消费者一定要通过OTA订酒店吗？

**证据支持的观察：** 酒店与连锁集团官网、搜索平台直订、旅游元搜索、替代性住宿均可能改写消费者的购买路径；Expedia在正式风险披露中认可这些替代压力。

**反证与不确定性：** 替代关系的强弱因国家、酒店档次和客群变化，不能用单一全球平均数衡量。

**建议的下一行动：** 分别研究直订、短租、搜索转介对预订转化、获客成本及复购的影响。

证据索引：[S6](#s6), [S2](#s2)

### 4. 供应商议价能力

**核心追问：** 平台实验提高用户转化，是否必然提升酒店合作收益？

**证据支持的观察：** 双边平台需要同时改善住宿供给的可展示性、可用房量和订单质量。Booking.com 2018年持续扩充住宿设施选择，供给质量与实验能力一起影响用户体验。

**反证与不确定性：** 新增加设施数不能替代有效库存或酒店净收益；流量排序可能造成酒店和平台利益分配冲突。

**建议的下一行动：** 引入酒店净收益、取消率、房态准确度及公平展示的守护指标。

证据索引：[S11](#s11), [S1](#s1)

### 5. 购买者议价能力

**核心追问：** 用户能轻松比价和切换平台时，什么可以减少对付费流量的依赖？

**证据支持的观察：** 可用供给、可理解的页面、转化体验与信任度影响选择；Booking集团2018年绩效营销44.47亿美元，显示渠道依赖仍然显著。

**反证与不确定性：** 不能因为测试量大就认为获客成本低或具有忠诚度优势；营销费用是集团口径。

**建议的下一行动：** 同时优化直达流量、重复购买和支付后完整订单价值，并按获客渠道分组实验。

证据索引：[S2](#s2), [S4](#s4)

## 第三部分：管理含义与决策边界

**战略建议（研究解释，不代表历史管理会议原话）：**

用供给可用性、流量依赖、用户转换成本与净长期价值审查实验价值，不用不兼容的间夜指标拼凑市占率。

### 证据与归因边界

- **公司自述与第三方数据须区分：** 公开采访中的口径、独立行业统计、正式披露的指标可能不同，不能直接拼接。
- **交易额、收入、利润与市场份额并不相等：** 使用前必须明确期间、分子分母与统计范围。
- **战略同时发生与严格因果归因并不相等：** 投资环境、竞争者反应和行业变化均可能影响结果。
- **成功叙事仍须允许反例：** 要审查行业淘汰者、竞争者领先区域与商户/消费者的不同体验。
- **DMAIC是方法映射：** 不得声称存在未经证实的控制图、控制限或试验结果。
- **战术有效不等于合法可持续：** 现金安全、消费者权益、商户价值和合规属于独立硬约束。

### 下一轮研究行动

- **新进入者威胁：** 拆解进入成本为供给接入、认证及内容、获客、客服履约和实验治理五项。
- **替代品威胁：** 分别研究直订、短租、搜索转介对预订转化、获客成本及复购的影响。
- **供应商议价能力：** 引入酒店净收益、取消率、房态准确度及公平展示的守护指标。
- **购买者议价能力：** 同时优化直达流量、重复购买和支付后完整订单价值，并按获客渠道分组实验。
