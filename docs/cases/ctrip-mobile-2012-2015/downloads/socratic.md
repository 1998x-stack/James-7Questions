# 苏格拉底式追问：携程移动互联网转型：从呼叫中心到移动交易平台

> 研究时段：2012—2015｜公司：携程 Ctrip｜行业：在线旅游 / OTA

> 方法学声明：本案例采用事后研究复盘；James 七问非携程官方固定题目，DMAIC 非经过证实的内部项目档案。

## 执行摘要

携程在2012—2015年推动由电话及PC向移动预订入口转型。公开财报证实移动交易迅速扩张、营收提升，但2014年研发及销售费用增加，归母净利润显著下降。本文将七连问及DMAIC应用于事后分析，而非声称复原当年的内部会议。

**核心判断：** 把‘移动占比增长=战略成功’改写为‘渠道迁移、交付能力和单位经济同时可验证’。

## 第一部分：理解现实与明确边界

**战略命题：** 竞争入口改变时，组织结构与工程交付能力必须随战略一起调整；渠道迁移成功不能等同于利润与因果归因成功。

|指标|观察值|口径与限制|来源|
|---|---:|---|---|
|2013年Q2酒店移动预订占比|超过20%|该季度酒店预订；非全公司交易占比|[S1](#s1)|
|2014年Q1酒店移动预订占比|超过40%|住宿预订业务该季度交易占比|[S2](#s2)|

### 经历的主要节点

- **2010｜推出移动应用：** 年报披露携程首次推出移动App [S4]
- **2013 Q2｜移动战略明确加速：** 酒店移动订单占比超过20%，机票约15% [S1]
- **2014 Q1｜移动端超过PC成为酒店预订主要平台：** 住宿预订移动交易占比超过40% [S2]
- **2014 Q4｜工程与组织转型复盘：** 16个业务团队承担自身移动产品，支付成功率一年提高约10个百分点 [S5]
- **2015｜增长与盈利归因再审查：** 2015年归母净利润含途家相关一次性会计收益，不能直接归因于移动转型 [S7]

## 第二部分：苏格拉底式追问分析

**方法目的：** 让战略假设具备可反驳性

### 1. 提出主张

**核心追问：** 我们认为大幅投入移动端就能赢得下一轮竞争，真的成立吗？

**证据支持的观察：** 移动端在2013—2014迅速成为酒店业务重要交易入口。

**反证与不确定性：** 战略论断强于现有单项证据。

**建议的下一行动：** 用多个指标而非单一占比描述成功。

证据索引：[S1](#s1), [S2](#s2)

### 2. 定义概念

**核心追问：** 所谓‘赢得竞争’是下载、订单、份额还是现金利润？

**证据支持的观察：** App下载和移动交易份额代表不同层面的结果，不能相互替代。

**反证与不确定性：** ‘下载量’累计口径不等于活跃用户。

**建议的下一行动：** 事先确定目标指标和观察时间。

证据索引：[S3](#s3), [S4](#s4)

### 3. 检查证据

**核心追问：** 我们用什么证明移动交易增长，而非只看高峰日？

**证据支持的观察：** 2013Q2和2014Q1季度酒店交易口径提供跨期观察。

**反证与不确定性：** Q2与Q1季节不同，跨期比较不构成因果识别。

**建议的下一行动：** 建立季度同比和可比产品线序列。

证据索引：[S1](#s1), [S2](#s2)

### 4. 寻找替代解释

**核心追问：** 增长可能只是智能手机普及的行业共同趋势吗？

**证据支持的观察：** 行业整体移动化是重要混杂因素，管理调整的独立贡献尚未识别。

**反证与不确定性：** 没有处理组和控制组，不能分配贡献比例。

**建议的下一行动：** 优先寻找同行可比数据及可重复实验。

证据索引：[S5](#s5), [S6](#s6)

### 5. 检查后果

**核心追问：** 收入增长和利润下降能否同时被称为成功？

**证据支持的观察：** 2014净营收+36%，归母净利-76%，研发+86%、营销+74%。

**反证与不确定性：** 短期利润下降并不自动证明战略失败。

**建议的下一行动：** 分析获客投入与生命周期价值及利润质量。

证据索引：[S3](#s3)

### 6. 形成可证伪命题

**核心追问：** 什么结果会让我们承认原来的战略判断有误？

**证据支持的观察：** 若移动成交增长长期无法改善净增客户价值或单位利润，必须重新评估投入结构。

**反证与不确定性：** 这是本研究提出的测试条件，并非携程当年公开承诺。

**建议的下一行动：** 预先设定停止阈值与复盘周期。

证据索引：[S3](#s3)

## 第三部分：管理含义与决策边界

**战略建议（研究重建，而非历史决议原文）：**

把‘移动占比增长=战略成功’改写为‘渠道迁移、交付能力和单位经济同时可验证’。

### 必须保留的区别

- **渠道迁移 ≠ 净增订单：** 仅凭移动交易占比不能识别真实增量与渠道替代。
- **营收增长 ≠ 单位经济改善：** 2014年研发和营销增幅高于净营业收入增幅，短期盈利承压。
- **同期变化 ≠ 管理措施的因果贡献：** 智能手机普及是重要混杂因素，未建立反事实对照。
- **管理者事后复盘 ≠ 正式DMAIC项目：** 不应虚构控制图、样本、置信区间或实验效果。
- **战术有效 ≠ 合法可持续：** 研究应包含法律、竞争影响和交易伙伴价值边界。

### 下一轮研究问题

1. 按产品线补全2012—2015年季度移动交易占比、订单量与净收入可比序列。
2. 区分App下载、月活用户、订单与复购，避免将累计下载当作活跃用户。
3. 根据同行公开财报建立对照序列，审查行业趋势与企业特定措施的差别。
4. 获取支付改进的期初期末基线、灰度分组与故障数据，才可能估计独立贡献。
