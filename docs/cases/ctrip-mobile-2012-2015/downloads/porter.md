# 波特五力：携程移动互联网转型：从呼叫中心到移动交易平台

> 研究时段：2012—2015｜公司：携程 Ctrip｜行业：在线旅游 / OTA

> 方法学声明：本案例采用事后研究复盘；James 七问非携程官方固定题目，DMAIC 非经过证实的内部项目档案。

## 执行摘要

携程在2012—2015年推动由电话及PC向移动预订入口转型。公开财报证实移动交易迅速扩张、营收提升，但2014年研发及销售费用增加，归母净利润显著下降。本文将七连问及DMAIC应用于事后分析，而非声称复原当年的内部会议。

**核心判断：** 不要只盯竞争对手；要看用户入口变化如何改变议价权与利润分配。

## 第一部分：理解现实与明确边界

**战略命题：** 竞争入口改变时，组织结构与工程交付能力必须随战略一起调整；渠道迁移成功不能等同于利润与因果归因成功。

|指标|观察值|口径与限制|来源|

### 经历的主要节点

- **2010｜推出移动应用：** 年报披露携程首次推出移动App [S4]
- **2013 Q2｜移动战略明确加速：** 酒店移动订单占比超过20%，机票约15% [S1]
- **2014 Q1｜移动端超过PC成为酒店预订主要平台：** 住宿预订移动交易占比超过40% [S2]
- **2014 Q4｜工程与组织转型复盘：** 16个业务团队承担自身移动产品，支付成功率一年提高约10个百分点 [S5]
- **2015｜增长与盈利归因再审查：** 2015年归母净利润含途家相关一次性会计收益，不能直接归因于移动转型 [S7]

## 第二部分：波特五力分析

**方法目的：** 竞争结构，而非市场份额排行榜

### 1. 行业内竞争

**核心追问：** 面对去哪儿、艺龙等，携程原来的服务优势是否足够？

**证据支持的观察：** 竞争从电话与PC延伸到移动搜索、发现、预订和支付体验。

**反证与不确定性：** 竞争格局因时间与市场定义而变化，不应以今天的份额回推2013年。

**建议的下一行动：** 按细分业务和交易入口开展竞争对标。

证据索引：[S1](#s1), [S4](#s4)

### 2. 新进入者

**核心追问：** 移动App是否降低了新的流量与交易入口建立门槛？

**证据支持的观察：** 移动终端提升了新型入口的战略重要性，不能假定既有渠道稳固。

**反证与不确定性：** 移动化不等于进入门槛单向下降；供应链和品牌仍可能形成壁垒。

**建议的下一行动：** 加快移动端产品能力与品牌入口建设。

证据索引：[S2](#s2), [S6](#s6)

### 3. 购买者议价

**核心追问：** 用户在移动端比价和切换的成本发生了什么变化？

**证据支持的观察：** 手机端使搜索与选择更加便捷，体验、价格、匹配效率成为潜在关键变量。

**反证与不确定性：** 这是一种机制假设，非当年用户切换成本的直接估计。

**建议的下一行动：** 测量转化、复购与实际净增交易。

证据索引：[S4](#s4)

### 4. 供应商议价

**核心追问：** 酒店和航司在多渠道分销下如何改变谈判地位？

**证据支持的观察：** 平台必须持续为供应商创造需求和交易效率，不能只依赖既有签约资源。

**反证与不确定性：** 供给侧议价能力需分酒店类别与城市，不应以统一均值替代。

**建议的下一行动：** 对供给覆盖、成交效率和商家收益进行联合分析。

证据索引：[S4](#s4)

### 5. 替代品与渠道

**核心追问：** 电话、PC、App之间是替代还是增量？

**证据支持的观察：** 2013Q2酒店移动订单已超过20%，2014Q1超过40%，说明入口结构发生明显变化。

**反证与不确定性：** 渠道份额提升不等于整体交易净增；可能有渠道内转移。

**建议的下一行动：** 区分渠道替代与新增用户带来的增长。

证据索引：[S1](#s1), [S2](#s2)

## 第三部分：管理含义与决策边界

**战略建议（研究重建，而非历史决议原文）：**

不要只盯竞争对手；要看用户入口变化如何改变议价权与利润分配。

### 必须保留的区别

- **渠道迁移 ≠ 净增订单：** 仅凭移动交易占比不能识别真实增量与渠道替代。
- **营收增长 ≠ 单位经济改善：** 2014年研发和营销增幅高于净营业收入增幅，短期盈利承压。
- **同期变化 ≠ 管理措施的因果贡献：** 智能手机普及是重要混杂因素，未建立反事实对照。
- **管理者事后复盘 ≠ 正式DMAIC项目：** 不应虚构控制图、样本、置信区间或实验效果。
- **战术有效 ≠ 合法可持续：** 研究应包含法律、竞争影响和交易伙伴价值边界。

### 下一轮研究问题

1. 按产品线补全2012—2015年季度移动交易占比、订单量与净收入可比序列。
2. 区分App下载、月活用户、订单与复购，避免将累计下载当作活跃用户。
3. 根据同行公开财报建立对照序列，审查行业趋势与企业特定措施的差别。
4. 获取支付改进的期初期末基线、灰度分组与故障数据，才可能估计独立贡献。
